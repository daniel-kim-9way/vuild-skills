# 동화 공방: 만들기

## 먼저 알아 둘 것

- 이 스킬 폴더(스킬을 열 때 받은 Base directory)를 `SKILL_DIR`라고 해요. 명령은 이렇게 불러요.
  - Mac·리눅스·WSL: `python3 "SKILL_DIR/../../scripts/sb.py" <명령>`
  - Windows: `py -3 "SKILL_DIR\..\..\scripts\sb.py" <명령>`
  - 아래에서는 줄여서 `sb <명령>`이라고 적어요. 참고 문서는 `SKILL_DIR/../../reference/`에 있어요.
- 끝 코드: 0 됨 · 1 입력을 고쳐야 함 · 2 준비가 안 됨(→ setup 스킬) · 3 사람에게 물어야 함(멈추고 메시지를 그대로 전해요).
- `sb voice`, `sb video`처럼 1분 넘게 걸릴 수 있는 명령은 Bash `timeout`을 600000(10분)으로 줘요. 기본 2분이 넘으면 중간에 꺼져요. `sb draw`는 백그라운드로 돌려요.
- 사람에게 하는 말은 한국어 입말로 짧게 해요. 동화 글은 한국 부모가 아이에게 읽어 주는 말로 써요.
- 비밀값(키)은 묻지도, 화면에 찍지도 않아요.
- 아이 사진은 글을 쓰는 Claude와 고른 그림 엔진에만 가요. 다른 곳(아티팩트, 웹, 다른 도구)에 올리거나 보내지 않아요.

## 0. 준비 확인

`sb doctor`. 2로 끝나면 setup 스킬을 먼저 해요. 첫 줄의 괄호 안 경로가 동화공방 폴더예요.

## 붙여 넣은 글이 오면

`[동화 공방 · 글 확인] <폴더>`, `[동화 공방 · 그림 확인] <폴더>`, `[동화 공방 · 동화] <폴더>`로 시작하면 확인 화면에서 복사한 글이에요. 첫 줄의 폴더로 일해요.

| 줄 | 할 일 |
|---|---|
| `N쪽 고친 글: "…"` | `sb story edit <폴더> N --text "…"` (표지는 0, 표지 글이 제목) |
| `N쪽 다시 써 줘: 까닭` | 까닭에 맞게 그 쪽 글을 다시 쓰고, 장면이 바뀌면 지시문도 고쳐서 `sb story edit` |
| `N쪽: …` | 글 확인 화면에서 체크 없이 적은 말이에요. 그 말대로 그 쪽 글을 고쳐요 |
| `이야기를 통째로 다시 써 줘` | 3단계로 새 초안을 쓰고 `sb story new` → 예전 폴더는 `sb story delete` (그림을 그리기 전에만) |
| `N쪽 다시 그리기: 까닭` | 까닭을 지시문에 또렷하게 넣어 `sb story edit <폴더> N --prompt "…" --note "까닭"` (지시문을 안 바꿔도 되면 `--redraw --note "까닭"`) → `sb draw <폴더>` |
| `N쪽 글 고치기: …` | 글을 고치고 7단계(목소리·MP4)를 다시 해요 |
| `더 하고 싶은 말: …` | 그 말대로 해요 |
| `좋아요. 이대로 그림을 그려 주세요.` | 5단계로 |
| `그림 좋아요. 목소리와 MP4를 만들어 주세요.` | 7단계로 |

## 1. 인물

- `sb people list`. 저장한 인물이 있으면 «지난번처럼 서준이랑 뭉치로 할까요?»처럼 물어요.
- 새 인물이면 이름, 아이 나이, 사진을 받아요. «사진 파일을 이 창에 끌어다 놓으면 경로가 들어가요»라고 알려 줘요.
  - 사진이 경로 대신 `[Image #1]`처럼 그림으로만 들어오면 경로를 알 수 없어요. 경로를 글로 붙여 넣어 달라고 해요(윈도우: 파일을 오른쪽 클릭 → «경로로 복사», Mac: option을 누른 채 오른쪽 클릭 → «경로 이름 복사»).
  - 아이: `sb people add --role child --name 서준 --age 4 --photo "<경로>"`
  - 인형(1~3개): `sb people add --role toy --name 뭉치 --photo "<경로>"`
- 같은 이름으로 다시 올리면 사진이 바뀌어요.

## 2. 이야기 고르기

- `sb story themes`의 주제 12가지 중에서 고르게 해요. AskUserQuestion은 선택지가 4개까지라서, 아이 나이와 요즘 일을 보고 셋을 추천하고 나머지는 «다른 주제»로 받아요.
- 요즘 있었던 일을 한 줄 받아요(안 적어도 돼요).

## 3. 글 쓰기

1. `reference/writing.md`를 읽고 그대로 따라요.
2. 인물 사진을 Read로 봐요.
3. `sb story examples <주제>`를 봐요.
4. 초안 JSON을 `<동화공방 폴더>/.draft.json`에 Write로 쓰고 `sb story new "<동화공방 폴더>/.draft.json"`.
   - `✗`가 나오면 초안을 고쳐 다시 `story new`.
   - `!`가 나오면 고칠지 판단해서 `sb story edit`로 고쳐요.
5. `sb page draft <폴더>` → «브라우저에 글 확인 화면을 띄웠어요. 고칠 곳을 적고 아래 «Claude에게 보낼 말 복사»를 눌러 여기 붙여 넣어 주세요. 그냥 말로 해도 돼요.»

## 4. 글 고치기

붙여 넣은 글이나 말대로 고치고 `sb page draft <폴더>`를 다시 해요. «좋아요»가 나올 때까지 해요.

## 5. 그림

1. `sb draw <폴더> --plan` 결과를 알려 줘요. fal.ai면 금액을 말하고 «그릴까요?»에 «네»를 받은 뒤에 그려요.
2. `sb draw <폴더>`를 백그라운드로 돌려요(Bash의 run_in_background). 끝나면 알림이 와요. 사람이 물으면 출력 끝줄로 몇 장째인지 알려 줘요.
   그리는 동안 같은 동화로 `sb draw`·`sb voice`·`sb video`를 돌리지 않아요(«그리는 중이에요»로 멈춰요). 글 고치기(`sb story edit`)는 해도 돼요.
   끝에 «아직 안 그린 쪽»이 나오면 그리는 동안 지시문이 바뀐 쪽이에요. `sb draw`를 한 번 더 돌려요.
3. 3으로 끝나면 멈추고 메시지를 그대로 전해요. 다른 엔진으로 바꾸지 않아요. 나중에 «이어서 그려 줘»라고 하면 같은 명령을 다시 돌려요(안 그린 쪽만 그려요).

## 6. 그림 확인 (Claude가 먼저)

1. `sb sheet <폴더>` → 나온 파일을 Read로 봐요.
2. `reference/art-check.md`대로 쪽마다 봐요. 의심되는 쪽은 그 그림 파일을 Read로 크게 봐요.
3. 고칠 쪽은 `sb story edit <폴더> N --prompt "…" --note "까닭"` → `sb draw <폴더>`. Claude가 스스로 하는 건 두 번까지예요.
   fal.ai면 다시 그릴 때도 돈이 들어요. `sb draw <폴더> --plan`으로 금액을 말하고 «네»를 받은 뒤에 그려요.
4. `sb page art <폴더>` → 다시 그린 쪽과 까닭을 짧게 말하고, 화면에서 확인해 달라고 해요.

## 7. 목소리와 MP4

1. `sb voice <폴더>` (1분 안팎)
2. `sb video <폴더>` (30초~1분). 음악을 바꾸려면 `--music twinkle`(반짝반짝 작은 별), `meadow`(들판), `off`.
3. `sb page book <폴더>` → MP4 경로를 알려 줘요. WSL이면 윈도우 다운로드 폴더에도 넣었다는 줄이 나와요.

## 나중에 고치기

- «귤 소풍 동화 5쪽 다시 그려 줘»처럼 오면 `sb story list`에서 제목으로 폴더를 찾아요. 애매하면 물어요.
- 그림을 고쳤으면 6단계 3번 → `sb video`(목소리는 그대로 둬요). 글을 고쳤으면 `sb voice` → `sb video`.
- 어느 쪽이든 마지막에 `sb page book`을 해요. 안 하면 동화 화면이 옛 글과 옛 그림을 보여 줘요.
